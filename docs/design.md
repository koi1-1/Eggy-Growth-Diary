> **权威规范：`design/6.png`（三屏：蛋气泡墙 / 领养成功 / 蛋主页）+ `design/7.png`（开屏 EARTH ONLINE）**

> ⚠️ 视觉为**原创像素风**，**不使用任何外部图片 / 精灵图 / webfont / 网络资源**：全部由纯 CSS + 内联 SVG 手作。

## 1. 色彩 Token

| 用途 | 变量 | 色值 |
|---|---|---|
| 天空（页面顶） | `--px-sky` | `#A9E4EE` |
| 海 / 主蓝（按钮、强调） | `--px-sea` / `--px-blue` | `#3D82D8` |
| 开屏紫 | `--px-purple` | `#8B7BD8` |
| 深蓝描边 / 主文字 | `--px-ink` | `#26304A` |
| 表面（卡片） / 次表面 | `--px-surface` / `--px-surface-2` | `#FFFFFF` / `#F6F9FA` |
| 粉（点缀） | `--px-pink` | `#FFA8C0` |
| 金（金币 / 太阳 / ENTER） | `--px-gold` | `#FFD14A` |
| 成功 / 危险 | `--px-green` / `--px-red` | `#3ECF8E` / `#E5484D` |
| 次文字 / 占位 | `--px-text-2` / `--px-text-3` | `#4A5570` / `#8590A6` |

约束：正文对比度 ≥ 4.5:1；彩底上的文字用白字 + `text-shadow: 2px 2px 0 var(--px-ink)` 描边，白底上用 `--px-ink` 深字。

## 2. 字体与排版

- 字体：`"Courier New", "SFMono-Regular", Consolas, "PingFang SC", "Microsoft YaHei", monospace`
- 全局 `image-rendering: pixelated`；数字启用 `font-variant-numeric: tabular-nums`
- 字号沿用：页面主标题 22–26px / 卡片标题 16–18px / 正文 15px / 辅助 13px / 标签 12px
- 像素大标题（EARTH ONLINE）用大写等宽 + 2px 深色描边

## 3. 间距与尺寸（4px 基准网格）

`--space-1..12`：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 px

- 卡片内边距 16px；内容块间距 16px；顶栏高 **52px**
- 常规控件高 **34px**，大控件 **40px**；移动端触控目标 ≥ 44px
- 圆角：`--radius-*` 一律 **0**

## 4. 像素视觉语言

- **像素框**：`border: 3px solid var(--px-ink)` + `box-shadow: inset 0 0 0 3px #fff` 得到「外深内白」双线框（领养弹窗、兑换卡、开屏主机）
- **像素投影**：`box-shadow: 4px 4px 0 0 rgba(38,48,74,.9)`，不用模糊阴影
- **像素按钮**：按下时 `transform: translate(2px,2px)` 且投影归零，模拟「按进去」
  - **主次分明**：`.btn` 默认是**次要**外观（浅底 + 墨色字），`.btn-primary` 才是蓝色主按钮。并排出现时（如「上一节 / 下一节」）两个都蓝就看不出主次了
- **像素对话尾巴**（`.todo-bubble`）：`::before` 是「橡皮」，用气泡自己的底色 `--bubble-bg` 把下边框盖掉一段让尾巴连通；`::after` 是尾巴本体（`height = |bottom| − 边框宽`，让顶端正好落在外边框下沿）。颜色走 `--bubble-bg` 而非写死底色，hover 变色时尾巴才不会对不上
- **像素装饰**：太阳 / 云 / 星 / 猫 / 门 一律用内联 SVG 的**阶梯矩形**（`shape-rendering="crispEdges"`）绘制

## 5. 本项目的应用

### 5.1 开屏（`#view-splash`，对应 `design/7.png`）
- 紫色天空渐变 + 像素云/星；中央「主机」像素双线框，内含「EARTH ONLINE」标题与「ENTER」金色像素按钮
- 右下角两只像素猫（内联 SVG）；「1/6」仅作装饰，**不实现多页轮播**
- ENTER 点击后记 `sessionStorage`（`dy-splash-done`），同会话刷新不再出现

### 5.2 一级页：蛋气泡墙（`#view-wall`，对应 `6.png` 第一屏）
- 天空→海渐变背景；气泡按蛋 `tone` **平涂像素色**、厚深描边 + 高光点 + 主题 emoji
- 保留 3 档直径 `lg 132 / md 106 / sm 84px` 与纵向错落偏移
- **文字一律用墨色 `--px-ink`**：浅色天上白字只剩 ~1.3:1 对比度，加描边也糊
- 气泡整体在剩余高度里**垂直居中**（`.bubble-cloud { flex:1; align-content:center }`），底部提示语用 `padding-bottom: 14vh` 抬到海色带以上
- 底部一条像素海色带（渐变色标在 **88%** 处硬切）

### 5.3 二级页：领养成功弹层（`#view-adopt`，对应 `6.png` 第二屏）
- 像素双线框弹窗 + 深色半透明遮罩；标题「【恭喜您领养成功！】」；按钮「好的」
- 蛋为像素蛋 sprite（随 tone 换色）

### 5.4 三级页：蛋主页（`#view-egg`，对应 `6.png` 第三屏）
- 顶栏标题「我的宠物」，蛋主题名作副标题；金币区 `🪙 + 金币数 + Lv.n 胶囊 + 「兑换」`（像素按钮）
- 蛋展示区（天空渐变）+ 右侧竖排「🍎 苹果 / 💧 喂水 / 🎨 换装」像素按钮
- 蛋主题名是**深色像素牌**（墨底白字），压在蛋上方——白字直接飘在浅青天上会糊
- 成长条：**像素分段条**（直角、2px 描边、平涂填充），保留 `#growth-fill` 百分比填充
- 分区：「**今天要做什么？**」+ **4 个像素气泡卡**（课程 / 复习 / 徽章 / 探索），整卡可点，键盘可达

### 5.5 四级页：课程详情 + 单节课

课程分**两层**：课程总览（6 张课卡的 bento 网格）→ 单节课详情页。

**课程总览页**：

```
h1  标题（XX 0→1 学习计划）
├ .course-principle  一句话排课原则（浅底 + 左侧深色像素竖条）
├ .lesson-grid       2 列网格，gap 12px
│   ├ Lesson1  .lesson-card--lg  grid-column: 1/-1，min-height 132px
│   ├ Lesson2  +  Lesson3        各半宽，min-height 96px
│   ├ Lesson4  .lesson-card--lg  整行
│   └ Lesson5  +  Lesson6        各半宽
└ .refs             参考来源（保留出处，不宣称原创）
```

- 每张课卡（`<button>`，整卡可点，键盘可达）：`.lesson-card__idx`「Lesson N」（等宽）+ `.lesson-card__icon` 图标 + `.lesson-card__name` + `.lesson-card__goal`（2 行截断）
- 卡片白底 + 2px 深描边 + 硬投影；hover 抬升，focus-visible 高对比描边
- 底栏 `.doc-foot`：「学完了，+30 金币」（**课程级一次性**）

**单节课详情页**：

```
顶栏：‹ 返回（回课程总览） | 第 N 课 · 课名
h1  课名
├ .stage-goal      本节目标
├ .stage-why       为什么排在这里
├ .stage-articles  学习文章有序列表：标题做成链接，下方 .art-why 是「为什么选它」
└ .stage-actions   行动任务：**方形像素复选框**（appearance:none 自绘，选中打勾）
底栏 .doc-foot--split：‹ 上一节 | 下一节 ›
```

- 行动任务勾选态存 `localStorage`（key 含蛋 id + 课次下标 + 任务下标），刷新后保留；不上报后端
- 参考来源标签如实标注素材来源：「来自知乎知识库」或「来自你的收藏」
- 外部文本（AI 生成 + 知乎文档）一律转义后渲染；链接只认 `http(s)`

### 5.6 五级页：复习测验 + 金币兑换
- 复习选项为像素按钮（直角描边）；正确态 `--px-green`、错误态 `--px-red`、选中态浅蓝平涂
- 兑换弹层为像素双线框；余额条、兑换行、价格标签像素化；金币不足整行 `disabled`

## 6. 蛋的配色（`.egg-tone-1..6`）

平涂像素色，每档含 `--egg-fill`（主色）与 `--egg-shade`（暗部）：

| 档 | 主色 | 暗部 |
|---|---|---|
| 1 蓝 | `#6FB2FF` | `#3D82D8` |
| 2 紫 | `#B48CFF` | `#8B7BD8` |
| 3 粉 | `#FF9EC0` | `#E06E96` |
| 4 绿 | `#6FDFA0` | `#3EAE72` |
| 5 琥珀 | `#FFC86B` | `#E09A2E` |
| 6 青 | `#6FD9E0` | `#3EA3AE` |

蛋本体由 `public/js/app.js` 的 `eggSVG(tone)` 生成内联 SVG，跨「领养弹层 / 蛋主页」复用。

**只画四层，顺序固定**：平涂主色 → 贴着右下轮廓的暗部（右侧一条竖带 + 右下角一段台阶）→ 左上两块阶梯白高光 → 深蓝描边。所有层套 `<clipPath>`，超出的部分自动被蛋形裁掉，矩形可以放心画大。

> 别再加斑点 / 纹理：16×18 的格子里多画一笔就糊成一个球——加过一版深色斑点，屏幕上读起来像蛋壳上的洞。

## 7. 无障碍

- 正文对比度 ≥ 4.5:1；所有交互元素可键盘访问，焦点态始终可见（高对比描边）
- 图标按钮提供 `aria-label`；动态提示使用 `aria-live`
- 支持 `prefers-reduced-motion`（呼吸 / 弹入动效自动关闭）
- 像素风**不牺牲可读性**：正文字号与行高沿用原规范，像素化只作用于边框、色彩、装饰与字体族
